CORE FLOWS TO IMPLEMENT

1) AUTH + ONBOARD
- Phone+OTP, selfie capture → face-match (basic cosine on embeddings; manual fallback queue)
- Profile prompts (fun, short), interests (multi-select), languages, nightlife vibe, safety prefs
- Verification badge on pass; block/limit features if not verified

2) DISCOVER: SWIPE + VIRTUAL ROOMS
- Swipe stack w/ daily soft cap for free users (build anticipation)
- Virtual Rooms: join/leave, hard cap=12, 20-min session timer, live presence via WebSockets, room chat
- Room types: open, partner-only, premium; geo-fenced entry near venue optionally
- Anti-creep rules: balanced queueing, message rate-limits, report → auto-mute

3) MATCH + CHAT
- On match, call AI Openers → return 3 concise, context-aware lines (Hinglish allowed), safe tone
- Stalled chat nudge (after 24h idle): propose 2 topic pivots + 1 IRL suggestion (nearby partner spot)
- Toxicity filter pre-send; image safety → blur until accept

4) IRL: DATE BOOKING + EVENTS
- “Set a Date”: choose partner venue, day/time, auto-generate sharable **QR discount**
- Events module: city feed, ticketing (₹), waitlist, host tools, QR check-in (Ticket.checked_in_at)
- Venue portal (admin): create perks, set inventory windows, view redemptions

5) CUBES + SEASONS + QUESTS
- Season length = 6 weeks; daily/weekly quests: “enter 2 rooms”, “send opener in 3 matches”, “attend mixer”
- Earn Cubes + XP; **sinks**: gifts, boosts, premium rooms, event discounts, profile spotlight
- Leaderboards (city + global); anti-grind caps; emphasize quality actions (first_reply<=6h, date_booked)

6) SAFETY & TRUST
- Deception/Spam heuristics: duplicate selfies, link spam, templated messages → shadow restrict + review queue
- Photo safety: NSFW detection → blur; “private mode” watermarks screenshots
- Reporting: one-tap, categories (harassment, scam, impersonation, obscene); SLA dashboard for moderators

7) MONETIZATION
- Plans: Lite ₹199/mo, Premium ₹699/mo, God Mode ₹1,499/mo (unlimited rooms, see-likes, 2× XP, 1 boost/wk, premium rooms, AI+)
- Microtransactions: Cubes bundles, Super Likes, room Boosts
- Events revenue: paid mixers ₹299–₹1499; VIP pass; brand-sponsored nights
- A/B city-wise dynamic pricing; student verification discounts

8) ANALYTICS (instrument every step)
Core events: signup_verified, profile_completed, room_joined, match_created, ai_opener_used, chat_10msg,
date_booked, event_ticket_bought, venue_qr_redeemed, report_submitted, subscription_started
Funnels: install→verify, match→first_msg, chat→date, events: ticket→check-in
Alerts: report rate >1.5% day, DAU drop >10%, women DAU <35%, verify fails spike
